# Evidesk

## Product statement
Evidesk is a local-first desktop research workspace for students, researchers, and OSINT analysts. It helps collect, organize, connect, search, and act on PDFs, links, notes, excerpts, citations, sources, and research tasks.

## Core promise
Turn scattered research material into structured, searchable dossiers.

## What it is not
- Not a generic AI chat app
- Not a cloud-first note-taking app
- Not just a PDF viewer
- Not a bookmark manager

## MVP goal
Allow a user to create topics, import PDFs, save links, write markdown notes, create excerpts/citations, tag items, connect materials across topics, search everything, and manage research tasks locally.

## Target users
- Students
- Researchers
- OSINT/open-source investigators

## Design principles
- Fast
- Local-first
- Clean
- Search-first
- Topic-centric
- Evidence-oriented
## MVP includes
- Topic creation
- Multi-topic relationships
- PDF import into internal library
- URL sources
- Markdown notes
- Quotes and excerpts
- Tags
- Tasks linked to sources/topics
- Global search
- Local backup/export
- Optional AI through user API key (later phase)

## MVP excludes
- Team collaboration
- Cloud sync
- User accounts
- Real-time collaboration
- OCR-heavy pipeline
- Autonomous agents
- Browser automation
- Vector embeddings as core dependency
- Complex citation styles engine
