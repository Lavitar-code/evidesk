# Evidesk — MVP Screens

## 1. App Shell
Elementi:
- sidebar sinistra
- top search
- area contenuto centrale
- pannello dettagli destro
- barra azioni contestuali

## 2. Topic View
Elementi:
- titolo topic
- descrizione topic
- tabs:
  - Overview
  - Sources
  - Notes
  - Quotes
  - Excerpts
  - Tasks
- quick actions:
  - Add PDF
  - Add Link
  - New Note
  - New Task

## 3. Source List View
Elementi:
- lista fonti
- filtri per tipo
- ordinamento
- tag visibili
- source status

## 4. Source Detail View
Elementi:
- titolo
- tipo source
- metadata
- topic collegati
- tag
- quote collegate
- excerpt collegati
- task collegati
- azioni:
  - edit
  - add quote
  - add excerpt
  - create task

## 5. Note Editor View
Elementi:
- titolo nota
- editor markdown
- stato autosave
- topic collegati
- tag

## 6. Search View
Elementi:
- input query
- risultati misti
- badge per tipo entità
- snippet
- topic correlati
- filtri

## 7. Add Source Modal
Scelte:
- PDF
- URL
- Note
- Manual Source

## 8. Task View
Elementi:
- lista task
- filtri per stato
- filtri per priorità
- task collegati a topic/source
